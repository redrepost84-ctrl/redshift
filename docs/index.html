Seeing "Windows protected your PC" (SmartScreen)?

Because Redshift is a free indie app without a paid Microsoft EV signing certificate, Windows Defender SmartScreen may show a blue prompt the first time you run RedshiftSetup.exe. Simply click More info → Run anyway. Every build is open-source and SHA-256 verified directly on GitHub Releases.
